O que aprendi com o GitHub

Um resumo dos meus aprendizados e projetos

GitHub HTML Publicação Acessibilidade Projetos

1. O que é o GitHub?

Aprendi que o GitHub é uma plataforma que permite guardar, organizar e compartilhar projetos de programação. Também é possível utilizar a plataforma para publicar sites e acompanhar as alterações feitas nos arquivos.

2. Criação de páginas HTML

Aprendi a criar páginas utilizando HTML, organizando conteúdos como títulos, textos, links e diferentes partes de um site.

  • Utilizar títulos e parágrafos.
  • Organizar conteúdos dentro de seções.
  • Adicionar links para outras páginas.
  • Utilizar CSS para personalizar o visual.

3. Publicação de sites

Aprendi a utilizar o GitHub Pages para publicar páginas HTML e transformar arquivos de um projeto em um site que pode ser acessado pela internet.

Também aprendi que é importante conferir os nomes dos arquivos e verificar se o site está funcionando corretamente depois de publicado.

4. Acessibilidade digital

Aprendi um pouco sobre acessibilidade digital e como ela ajuda diferentes pessoas a utilizarem um site. Utilizei ferramentas como WAVE e Lighthouse para identificar problemas nas páginas.

  • Verificar o contraste entre textos e fundos.
  • Melhorar a leitura das informações.
  • Identificar possíveis erros na página.
  • Buscar melhorias para tornar o site mais acessível.

5. Projetos que desenvolvi

Durante meus aprendizados, trabalhei na criação e melhoria de páginas de sites, colocando em prática os conhecimentos adquiridos.

  • Projeto Court Elite.
  • Ideia de uma loja com foco em acessibilidade.
  • Correção de problemas de contraste.
  • Publicação e verificação de páginas na internet.

6. O que esses aprendizados me proporcionaram?

Esses aprendizados me ajudaram a entender melhor como funciona a criação de sites, desde a montagem da página até a publicação. Também aprendi que desenvolver um site não é apenas fazer ele funcionar, mas pensar na organização, aparência e acessibilidade para quem vai utilizá-lo.
